What counts as a favourable rate?

A currency is marked favourable when the amount bought per CAD is within 0.5% of its best rate over the past 90 calendar days, or at least 2% above its preceding 30-day average. A higher amount received per CAD is better.

This compares recent rates; it does not predict what happens next. Data more than four calendar days old is marked stale and cannot trigger a favourable-rate signal.

The website refresh is scheduled for weekdays around 2:15 PM Vancouver time. Publishing can be delayed. Holidays retain the last available fixing. The Mac script runs independently; browser alerts run only while the page is open. Use the Mac script for alerts when the page is closed.
